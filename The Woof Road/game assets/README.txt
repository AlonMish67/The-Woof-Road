Name of the game: The Woof Road

Game play: 
     In The Woof Road, you play as a dog walking in the forest. trying to collect food while avoiding eating litter and dangerous wild animals.
     Objects (like food and threats) move upward from the bottom of the screen, and your goal is to dodge hazards and catch helpful items.

     Objective: 
	Get as many points as possible, stay safe, and keep the doggy happy and healthy!


Installation:
     This game requires Python and the following libraries:
	pygame (needs to be downloaded - to download run:      pip install pygame)
	random
	sys

How to play:
	Use arrow keys to move the dog in any direction
	Catch food items to earn points
	Catch first aids to get more health / points (if health is full)
	Avoid litter and dangerous animals to stay alive
	Press M to mute/unmute
	Press Esc to pause or unpause the game.


Folder structure:
	1) FinalProject.py - main code of the game (contains the main loop and logic)
	2) dogForGame.py - contains dog movement logic
	3) goodsForGame.py - contains good objects logic
	4) dangersForGame.py - contains danger objects logic
	5) game assets- folder containing game images
